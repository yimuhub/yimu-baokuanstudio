## P0-3 生图 API 可配置（图文并茂自动化）

- 「设置」面板新增 **配图** 区块：
  - 默认走 apipool 免费图像模型（agnes image-2.x-flash），零成本；也可填任意 OpenAI 兼容生图 API
  - 三个开关：**封面图**（必开）/ **段落配图**（按关键词自动配）/ **小红书卡片背景**（AI 底图）
- 正文自动插图流程：写稿时同步产出「每节配图提示词」→ 调生图 API → 图存 `data/drafts/{id}/img/` → 公众号 HTML 内联上传素材、小红书卡片可换 AI 底图
- 兜底：生图失败自动回落到现有 HTML 信息卡，不断流

## P0-4 多维评分考核机制（核心新增）

### 评分卡（100 分，7 维度）

| 维度 | 分值 | 评什么 |
|---|---|---|
| 标题钩子 | 15 | 数字/悬念/身份代入，≤30字，平台适配 |
| 内容价值 | 25 | 信息增量、干货密度、真实可信、切题度 |
| 结构逻辑 | 15 | 钩子→共鸣→干货→CTA 完整，段落功能清晰 |
| 语言风格 | 15 | 活人感、无 AI 味、平台语感（小红书口语化/公众号深度） |
| 图文配合 | 15 | 配图与段落相关、卡片节奏、封面吸引力 |
| 排版可读 | 10 | 分节/列表/长度合规/留白节奏 |
| 互动潜力 | 5 | CTA 明确、能引导评论/收藏/转发 |

### 等级与流转

```
生成 → 评分（LLM-as-Judge 独立评审，逐维度打分+理由+3条改进点）
  ├─ <75  不合格(红)：自动带改进意见重写，最多 3 轮（可配置）
  ├─ 75-84 合格(绿)：停止，进草稿箱待人工
  ├─ 85-94 良好(蓝)：同上
  └─ ≥95  优秀(金)：同上
人工干预：草稿页可「重新评分」「定向重写」（给一句话指令，如"开头改成悬念式"）
```

- 每次评分+每轮重写都留痕（第几轮、每轮分数变化、改进点），草稿页可见
- 合格线 75 / 轮数上限 / 维度权重均可在「设置」调
- 技术实现：LLM-as-Judge 轻量自研（独立评审调用，与写稿分开），借鉴 GitHub 上 llm-eval-harness 的 rubric 评分模式，不引入重型框架

## P1 草稿页 UI 重构

```
┌────────────┬──────────────────────────────┐
│ 草稿列表    │  详情工作区                    │
│ ·标题+来源  │  Tab: 公众号|小红书|头条|拆解|评分 │
```
