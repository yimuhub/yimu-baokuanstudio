# 广告角度与类目套路技能

> 方法论借鉴 static-ad-concept-generator（MIT）的 16 种广告角度与类目套路，重写为中文并适配 V7 广告创意分析 Agent。只用方法论思想，不复制原文代码。

## 适用场景

- 卖点提炼前：先选 2–3 个广告角度，避免千篇一律
- 按产品类目自动套用对应打法

## 二、类目套路库

### 💄 美妆护肤
- **前后对比**：同一光线、同一角度，左右分屏
- **质地特写**：膏体流动性、上脸延展性，微距慢镜头
- **流程植入**："早 8 点护肤流程"日常感植入
- **成分叠加**：成分名大字 + 功效动画

### 📱 3C 数码
- **参数可视化**：把"5000mAh"变成"刷 8 小时视频还剩 30%"
- **场景实测**：真实场景跑分、续航、拍照对比
- **竞品对比**：同价位横向 PK（注意合规）
- **开箱**：仪式感开箱，第一视角

### 🍜 食品饮料
- **食欲特写**：热气、拉丝、爆汁，慢镜头是灵魂
- **热量透明**："一包 = 半个苹果的热量"
- **便捷性**："3 分钟搞定一餐"
- **社交场景**：聚会、办公室、深夜食堂

### 👗 服装穿搭
- **上身前后**：换装一秒切换
- **场景穿搭**：通勤/约会/度假，一衣多穿
- **面料特写**：垂感、透气孔、走线，微距
- **尺码包容**：不同身材同款展示

## 三、Brief 五段式（动笔前先填）

生成卖点前，先填完这五段，卖点质量翻倍：

1. **产品一句话定位**：______（例：一款能装进包里的迷你榨汁机）
2. **受众三痛点**：主痛点______ / 次痛点______ / 当前替代方案______ / 购买顾虑______
3. **核心利益点**（1 句）：______
4. **支撑点**（≤3 个）：①______ ②______ ③______
5. **证据**（评价/数据/奖项）：______

## 四、与 V7 流水线的配合

- `extract_selling_points()` 调用前：先用本技能选 2–3 个角度 + 识别类目套路，把角度和套路拼进 prompt
- 类目识别：从产品描述关键词自动判断（面膜/精华→美妆；手机/耳机→3C；零食/茶→食品；连衣裙/外套→服装），识别不出按通用处理
- "AI 生成卖点"按钮可升级：一次生成 3 版不同角度的卖点（天然 A/B 素材）
