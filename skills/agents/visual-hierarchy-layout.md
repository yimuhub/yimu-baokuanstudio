现代多端排版黄金视觉层级军规：
1. **视觉呼吸感与空间韵律**：
   - 严格遵循 1.75 - 2.0 行高，段落之间空行，单段中文不超过 4 行。
   - 避免整屏纯文字：阅读视线每滑动 1.5 屏必须遇到视觉缓冲点（加粗金句、轻量卡片框、引用强调、分割线或配图）。
2. **三级标题序列系统**：
   - 一级大节使用数字或前缀装饰（如 `01 / ` 或 `一、`），带底色衬底或左侧强调竖条。
   - 二级小点使用加粗圆点或符号（如 `▪️` / `▸`），严禁层级错乱。
3. **色彩克制法则**：
   - 全文严格遵循 60-30-10 配色定律（60% 背景/黑白灰正文，30% 结构辅助色，10% 品牌主色/点睛高亮色）。
   - 重点加粗字数不超过单段的 15%，避免“满篇皆重点”。
4. **移动端首屏与尾屏锚定**：
   - 首段破题前置核心主张，尾段精美排版结语，提供清晰行动号召。
