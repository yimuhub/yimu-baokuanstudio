# Harness · 小清新视觉系统规约（第三轮）

**硬规则**
1. **全站只有一个强调色（陶土橙）**，只用于「主操作 / 当前选中 / 关键数字」。绿色只表示成功/完成；蓝/琥珀/红只表示信息/提醒/危险。
2. **禁止任何 `linear-gradient` 彩色渐变**（含按钮、封面、进度条、头像底）。已有渐变一律改纯色；进度条用单色 + 浅底轨。
3. **禁止彩色描边、彩色大色块、荧光/高饱和图标**。图标一律 `currentColor` 单色线性；工具条不得用彩色 emoji 当图标（业务数据里的 emoji 文案可保留）。
4. 顶栏浅色态为**半透明奶白 + 底部 1px 细线**（可用 `backdrop-filter: blur(12px)`），深色为同层级深色，不做简单反相。
5. 深浅两态必须保持同一信息层级：卡片仍「纯白/深灰卡」，边框仍极浅，文字仍深灰/浅灰。

## 二、形状与阴影

- 圆角：卡片/面板 `--hx-radius` 10px；控件（按钮、输入、tab）`--hx-radius-sm` 8px；胶囊 `--hx-radius-pill`。
- 阴影：静置卡只用 `--hx-shadow-sm`；浮层（菜单/弹窗/抽屉）用 `--hx-shadow-md`～`lg`。**禁止双层卡片**（卡内再套带阴影的卡 → 内层去掉阴影、改 `--hx-line` 描边）。
- 留白：卡片内边距 ≥14px，区块间距 12–16px；列表行高 ≥40px（紧凑处 ≥34px）。
- 边框：1px `--hx-line`；hover 用 `--hx-line-strong`；不要 2px 粗边。

## 三、组件语言

- **按钮体系**（同屏最多一个 primary，其余低饱和）：
  - `primary`：实心 `--hx-accent` + `--hx-on-accent` 文字，8px 圆角，无渐变无外发光；
  - `ghost`：透明底 + 1px `--hx-line` 描边 + `--hx-ink-2` 文字；hover 底 `--hx-hover`；
  - `tonal`：`--hx-accent-soft` 底 + `--hx-accent-ink` 文字（强调但克制）；
  - `subtle`：无边框，`--hx-ink-3` 文字，hover 才出现 `--hx-hover`。
- **页签 tab**：小号（11.5–12.5px）、默认 `--hx-ink-3`、选中 `--hx-accent-ink` + 1px 底边或 `--hx-accent-soft` 底；不要彩色实心胶囊。
- **列表/表格**：行间 1px `--hx-line`，hover `--hx-hover`，选中 `--hx-accent-soft`；不用斑马纹重色。
- **空态**：一句说明（`--hx-ink-3`）+ 至多一个 ghost 按钮；插画改单色线条或直接去掉。
- **滚动条**：宽 8px，thumb `--hx-scroll`，轨透明。
- **弹窗**：面板 `--hx-panel`、圆角 10、遮罩 `--hx-overlay`、阴影 `--hx-shadow-lg`；危险操作按钮才用 `--hx-red`。

## 四、内容工作台专项（重灾区）

- 署名身份保持 meta 行内简洁形态（不要再出现橙色横条/橙色描边卡）。
- 工具栏（AI 改写提升 / AI 智能配图 / 配图 / 复制·导出 / 多端发布 / 更多 / 进阶面板入口）全部改成 **ghost 或 subtle 组**：统一高度、统一圆角、单色图标；组内不加底色块。
- 编辑区上方平台/字数/同步状态收成一行紧凑 meta，用 `--hx-ink-3`；状态成功用 `--hx-green` 仅文字色。
- 工具栏下方的富文本操作条（H3/加粗/列表/引用/分割线/标签/配图/纯排版换肤/富文本）改为单色文字按钮，`--hx-line` 描边或纯文字。
- 底部动作条：只保留**一个** primary（「保存并重新渲染」或发送），其余 ghost。
- 历史版本/合规体检/7 维评分/拆解报告 → 右栏预览页签与「更多」菜单，保持真实可点，不铺在中栏。

## 五、左右栏伸缩（每页可用）

- 左栏：所有页面可收起；**收起（68px）后必须仍有一个可见可点的展开按钮**（Logo 胶囊 + 展开控件都要在 68px 内）；状态持久化（`yimu.hx.railMini`），刷新保持。迷你态图标/hover/激活态仍可用。
- 右栏：**所有页面**（含 dashboard/studio/pricing/profile）可收起/展开；收起后必须有可见入口（顶栏按钮优先，中栏右缘可加 40px 贴边浮标），不得消失；状态跨页记忆。窄屏抽屉态同样可开可关。
- 两栏按钮在亮/暗、正常/迷你、1440/1231/1024 下都可见可点；互不遮挡、不压中栏、不出横向溢出。
- 内容页右栏打开默认停在「预览」并停靠真实 `#wb-preview-pane`；折叠回 `#hxPreviewHome` 并保留平台/评分/报告/合规/历史/滚动状态（沿用既有停靠契约）。

## 六、验收

- 8 个一级页 + 主要二级页逐页检查；每页至少 1440 浅、1231 深、1024 各一。
- 硬性：无第四列、文档级横向溢出 0、无遮挡、0 pageerror、Classic/V11 的 `hx-` 节点 0。
- 每个改动文件需 `node --check`（JS）与 `harness_ui_verify.py` hard_fail=0。
