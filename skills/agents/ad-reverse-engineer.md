# 爆款广告逆向拆解技能

> 方法论借鉴 creatify-ai/video-ad-reverse-engineer（MIT），重写为中文并适配 V7 广告创意分析 Agent。只用方法论思想，不复制原文代码。

## 适用场景

- 用户上传一条爆款竞品广告（文字描述/链接/截图），输出可复用的分镜模板
- 把"别人跑量的广告结构"套用到自家产品上

## 一、12 种广告格式目录

先识别这条广告属于哪种格式，再谈拆解：

| # | 格式 | 特点 | 适合产品 |
|---|------|------|----------|
| 1 | UGC 口播 | 真人对镜头说话，生活化背景 | 美妆、食品、日用品 |
| 2 | 产品演示 | 纯产品操作演示，无真人 | 3C、小家电、工具 |
| 3 | 前后对比 | 使用前/使用后强烈反差 | 美妆、清洁、健身 |
| 4 | 证言合集 | 多人快剪证言拼贴 | 课程、保健品、App |
| 5 | 痛点解决 | 先放大痛点，再给出方案 | 母婴、健康、家居 |
| 6 | 清单体 | "3 个理由告诉你…" | 快消、新品上市 |
| 7 | 开箱 | 拆包装全过程 | 3C、潮玩、美妆礼盒 |
| 8 | 日常植入 | 产品自然出现在生活流中 | 食品、饮料、服饰 |
| 9 | 竞品对比 | 直接 PK（注意合规风险） | 3C、家电 |
| 10 | 故事弧 | 微剧情，有起承转合 | 品牌广告、高客单价 |
| 11 | 纯文字动画 | 无实拍，文字+动效 | 知识付费、App |
| 12 | 快剪混剪 | 高频剪辑+卡点音乐 | 服饰、潮牌、零食 |

## 二、7 步逆向拆解法

**看 3 遍**：第 1 遍看整体感觉，第 2 遍看分镜结构，第 3 遍看细节执行。

### 第 1 步：识别格式
对照上面的 12 种格式，确定这条广告的主格式（可能 80% 一种 + 20% 另一种混合）。

### 第 2 步：分析 Hook（0–3 秒）
- 逐字稿：前 3 秒说了什么（一个字不差记下来）
- 首帧画面：第一帧是什么（产品/人脸/文字/场景）
- 音频：有没有音效、音乐起點
- 字幕：首帧有没有大字，是什么字

### 第 3 步：场景结构映射
按时间轴列出每个镜头：

| 时间戳 | 画面 | 音频/口播 | 字幕 | 机位/运镜 | 目的 | 转场 |
|--------|------|-----------|------|-----------|------|------|
| 0–3s | … | … | … | … | 抓注意力 | 硬切 |
| 3–8s | … | … | … | … | … | … |

### 第 4 步：提取脚本模式
- 总字数 / 语速（字/秒）
- 语气：兴奋 / 冷静 / 闺蜜式 / 专家式
- 分段结构：Hook 占几秒，正文几个卖点，CTA 占几秒

### 第 5 步：视觉策略
- 画幅（9:16 / 16:9 / 1:1）
- 配色：主色是哪 2–3 个
- 灯光：自然光 / 影棚光 / 氛围光
- 字幕风格：大字报 / 小字条 / 花字
- B-roll：用了哪些空镜
- 出镜人：什么形象，几个人
- 品牌元素出现几次、在哪

### 第 6 步：节奏分析
- 总剪辑数 / 平均镜头长度
- 能量曲线：开头高→中间稳→结尾高的"微笑曲线"，还是全程高能
- 音乐卡点：剪辑点是否踩在鼓点上

### 第 7 步：输出可复用模板
把上面拆出来的东西变成填空式模板：

```
UGC 口播
痛点提问式："______（痛点），你是不是也______？"
______（人脸特写/产品特写/文字）
卖点瀑布：卖点1______ → 卖点2______ → 卖点3______
限时优惠式："现在下单______，还送______"
9:16，自然光，______色调，大字字幕
共__个镜头，平均__秒/镜
```

## 三、使用流程（V7 落地）

1. 用户提供爆款广告（描述文字 / 视频链接 / 截图 + 口播文案）
2. Agent 按 7 步输出拆解报告 + 填空模板
3. 用户填入自家产品信息
4. 模板直接喂给广告脚本生成流程（`generate_ad_script`）

## 四、注意事项

- 只学结构和手法，不抄文案、不抄画面——合规红线
- 拆解时标注"这条为什么跑量"的核心洞察（一句话），比模板本身更重要
- 同一产品建议拆解 3 条以上同类爆款，找共性而非个案
