# 广告创意评估技能

> 方法论借鉴 creatify-ai/ad-creative-evaluator（MIT），重写为中文并适配 V7 广告创意分析 Agent。只用方法论思想，不复制原文代码。

## 适用场景

- 广告脚本/分镜生成后，先自评再出片
- 低于 7 分自动改一版，形成"评估 → 定位最弱维 → 定向重生成 → 再评估"闭环

## 一、8 维加权评分

每维 0–10 分，按权重算总分（满分 10）：

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| Hook 有效性 | ×1.5 | 前 3 秒能否让人停下手指？有悬念/冲突/反常识吗 |
| 信息清晰度 | ×1.3 | 3 秒内能说清"这是什么、给谁用"吗 |
| CTA 强度 | ×1.3 | 行动指令明确吗？有紧迫感/利益点吗 |
| 受众精准度 | ×1.2 | 说的是目标人群的语言吗？痛点抓得准吗 |
| 视觉质量 | ×1.0 | 画面有质感吗？产品是否清晰醒目 |
| 节奏结构 | ×1.0 | Hook/正文/CTA 配比合理吗？有拖沓吗 |
| 情绪共鸣 | ×1.0 | 能唤起渴望/恐惧/好奇/认同吗 |
| 静音可看性 | ×0.7 | 关掉声音，靠字幕和画面能看懂 80% 吗 |

**总分公式**：Σ(维度分 × 权重) / Σ权重

## 二、三专家视角

同一条广告，让三个"专家"各看一遍，每人有一份红灯清单：

### 🚀 效果营销专家（看转化）
- Hook 3 秒内有没有出现产品或核心利益点
- CTA 有没有明确的行动指令（"点击""下单""领取"）
- 有没有至少一个信任状（数据/评价/权威背书）
- **红灯**：看完不知道卖什么 / 没有 CTA / 全程自嗨没讲用户利益

### 🎬 创意总监（看工艺）
- 前 3 秒视觉冲击力够不够
- 镜头语言有变化吗（别全是固定机位口播）
- 字幕/配色/音乐风格统一吗
- **红灯**：一眼 AI 塑料感 / 产品全程小得看不清 / 音乐画面两张皮

### 👤 目标消费者（看真实感）
- 说的是人话吗（有没有广告腔）
- 痛点是我的痛点吗
- 我会看到一半划走吗，在哪一秒
- **红灯**："这又是一条广告"的感觉 / 痛点不对 / 太长

## 三、评分 → 行动映射

| 总分 | 行动 |
|------|------|
| 8.5+ | 直接投放 |
| 7.0–8.4 | 微调最弱的一维 |
| 5.5–6.9 | 修最弱的两维，重出一版 |
| <5.5 | 推倒重来，换 Hook 公式或换广告格式 |

## 四、评估闭环（V7 落地）

```
生成脚本 → 8 维打分 + 三专家过一遍 → 总分 ≥7？ → 是：出片
→ 否：定位最弱维 →
定向重生成（只改最弱维）→ 再评估
```

- 最多循环 2 次，2 次后仍 <7 分则换 Hook 公式重来
- 评估报告要包含：总分、各维得分、最弱维、具体修改建议（一句话）

## 五、输出格式

```
总分：7.8/10
Hook 有效性：8 ×1.5 | 信息清晰度：9 ×1.3 | CTA 强度：6 ×1.3 | ……
最弱维：CTA 强度（6 分）
修改建议：CTA 缺少紧迫感，建议加"前 100 名半价"限时钩子。
专家红灯：无 / 有（列出）
结论：微调后可投放 / 需重出一版
```
