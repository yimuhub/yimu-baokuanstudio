# Skill：合规仿写

> 移植自项目 A `app/imitate.py`（imitate / revise）。两步 LLM 调用：初稿 + 强制合规自检。

## 适用场景

- 有对标爆款 + 骨架（拆解 skill 产出），要出一篇同结构不重样的初稿
- 初稿被质检打回，需要按方向标签改写

## 输入

- `keyword`：关键词；`platform`：平台码（如 gzh）
- `skeleton`：拆解 skill 产出的骨架
- `ref_titles`：参考爆款标题；`title_hint`：标题 hint（可选）

## 输出

1. Markdown 初稿（含 3–5 个候选标题）
2. 合规自检报告：通过项 / 风险项 / 建议替换处 + 三档结论（绿灯可验收 / 黄灯需人工复核 / 红灯重写）
3. 打回重写记录：`rewrite_chain` / `rewrite_round`（第几轮、为什么打回）

## 核心规则

### 改写边界铁律（逐字保留）

1. **可以借**：结构骨架（段落节奏 / 小标题排布 / 钩子类型 / 信息密度）、标题模式
2. **不能抄**：观点、案例、数据、原句。这是合规红线，不是风格问题
3. 初稿里出现的「我」的经历 / 数据 / 结论，必须是待填空标记（如 [待你补充的亲身经历]），不能由 LLM 编造事实

### 合规自检四问（temperature=0.3 独立调用）

1. 有没有照抄原文 / 案例 / 数据？
2. 有没有 LLM 编造的"我"的经历 / 数据 / 结论？
3. 有没有套话堆砌、AI 腔（"综上所述""赋能""抓手"等）？
4. 篇幅是否落在平台规格内？

### 打回重写 10 方向标签

hook / data / title / story / layout / quote / emotion / contrary / utility / social

### Prompt 要点

- 初稿 system："只借结构不抄内容"（temperature=0.7, max_tokens=4096）
- 改写 prompt 注入：评分建议 + 改写方向 + 相关 skill 规范摘要

## 质量门

- [ ] 初稿中所有"我的经历/数据/结论"都是待填空标记，零编造
- [ ] 合规自检四问全部通过才给绿灯；任一红线命中直接红灯重写
- [ ] 兜底情况（如无可用模型走规则模板）必须如实写明原因，不谎称正常产出
