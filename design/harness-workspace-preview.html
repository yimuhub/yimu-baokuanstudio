Harness 工作台 · 四工作区

UI 方案说明 · v0.2

不是把现有功能搬进三栏，而是把工作台拆成四个连续的工作区：任务、内容、采集、设置。 每个工作区都保持「左导航、中工作区、右上下文」的同一套骨架，切换时只换内容，不换操作习惯。

01 四个工作区，一套骨架

01
任务 · 恒定对话

左栏是任务中心，中栏是唯一主轴对话，右栏是资产 / 浏览器 / 预览。对话、计划、工具调用、产物入口都在这里闭环。

02
内容工作台 · 编辑即预览

左栏草稿箱，中栏 Markdown 编辑，右栏同屏给预览、7 维评分与发布。改稿和判断成稿质量不再跨页。

03
采集工作台 · 链接到素材

左栏采集记录，中栏粘贴链接与结果卡，右栏拆原文、爆款基因和可用素材，采集完直接进入仿写。

04
系统设置 · 配置即检查

左栏分类导航，中栏表单，右栏实时检查、变更记录和帮助。设置不是深埋的后台，而是可看见结果的工作区。

02 关键交互规则

  • 工作区切换顶部与左栏同步高亮，主按钮随工作区变为「新建任务 / 新建草稿 / 采集链接 / 保存设置」。
  • 舞台 Tab 按工作区隔离任务看资产，内容看预览 / 评分 / 发布，采集看原文 / 基因 / 素材，设置看检查 / 变更 / 帮助。
  • 右栏常驻但可收起宽屏三栏并排；窄屏默认专注中栏，右栏以抽屉覆盖，关闭按钮一键返回。
  • 专注模式⌘⇧P 或右上角按钮收起右栏，中栏自动变宽，任务状态不丢。

03 和现在的区别

A
从「功能目录」到「工作区骨架」

现有功能不再各占一个页面，而是收进四个稳定工作区。左栏导航跟随工作区变，但中栏和右栏的位置始终不变。

B
从「单工作台」到「多工作台并列」

任务、内容、采集共享一套任务上下文与资产归档；设置也不再是后台孤岛，而是可以看到检查结果的第四工作区。

C
从「操作完再切页」到「操作即见结果」

内容页面改了正文，右栏立即刷新预览；采集页解析完链接，右栏立即出现原文与爆款基因；设置改完，右栏检查实时反馈。

04 建议落地顺序

  • 第一步：任务工作区 + 三栏外壳 + 舞台开合，先把高频创作流跑通。
  • 第二步：内容工作台迁入草稿箱 / 编辑器 / 预览评分，接现有 7 维评分接口。
  • 第三步：采集工作台与设置页迁入同一骨架，复用现有采集解析与配置接口。
  • 第四步：补任务多开、搜索、归档、快捷键与真实发布动作。
