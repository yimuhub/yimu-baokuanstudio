# AI 产品广告短片创意技能

> 方法论借鉴 creatify-ai/video-ad-generator（MIT）的 Standalone 创意框架，重写为中文并适配 V7 广告短片流水线。只用方法论思想，不依赖其商业 API。

## 适用场景

- 给产品做 15/30/60 秒 AI 广告短片：卖点提炼 → 广告脚本 → 分镜
- 需要"黄金 3 秒"开场钩子（Hook）+ 结尾行动号召（CTA）
- 与 `core/ad_video.py` 流水线配合：本技能负责创意层，引擎负责合成层

## 输入

- 产品名称、产品描述（一句话或一段）
- 目标人群（可选，不给则按大众消费品假设）
- 时长：15 / 30 / 60 秒；画幅：9:16（默认，信息流）/ 16:9

## 输出

- 卖点清单：3–5 个核心卖点（每条 ≤20 字，按说服力排序）
- 广告脚本：Hook（前3秒）+ 正文 + CTA 三段式口播文案
- 分镜表：每 3–5 秒一个镜头（镜头/时长/画面描述/口播/字幕）
- 英文素材检索词：3–4 个（给 Pexels 搜免费视频用）

## 核心规则

### 一、5 种 Hook 公式（开场 3 秒，二选一，最多用一种）

1. **痛点提问式**："还在为 XX 烦恼吗？"——直接点名目标人群的痛，疑问句收尾
2. **惊人数据式**："90% 的人都不知道……"——数字+反差，制造信息缺口
3. **场景代入式**："早上 8 点，你又在……"——具体时间+具体动作，让观众对号入座
4. **反常识断言式**："别再 XX 了，真正有用的是……"——否定常见做法，立新认知
5. **悬念留白式**："3 秒后，你会感谢我点开这条视频"——直接要完播

**选择原则**：高客单价/决策重 → 用 1、4（理性说服）；低客单价/冲动消费 → 用 2、3、5（情绪驱动）。

### 二、5 种脚本正文结构（Hook 之后的主体，按产品类型选一种）

1. **PAS（痛点-激化-解决）**：痛点 → 不解决的后果放大 → 产品登场解决。适合：功效型产品（护肤、工具、课程）
2. **卖点瀑布**：卖点 1 → 卖点 2 → 卖点 3，层层加码，每个卖点配一个画面证据。适合：功能多的 3C/家电
3. **信任背书叠加**：用户评价 → 数据 → 权威认证，信任状三连击。适合：新品牌、客单价高
4. **前后对比**：用之前（糟）→ 用之后（好），同一场景镜像对照。适合：效果可见的产品（清洁、美妆、收纳）
5. **场景植入**：把产品放进一天的生活流（早/午/晚），不讲参数只讲体验。适合：生活方式品类（食品、家居、服饰）

**时长拆解**：15 秒 = Hook(3s) + 正文(9s，1–2 个卖点) + CTA(3s)；30 秒 = Hook(3s) + 正文(21s，3 个卖点) + CTA(6s)；60 秒 = Hook(5s) + 正文(45s，4–5 个卖点) + CTA(10s)。

### 三、6 种 CTA 模板（结尾，按营销目标选一种）

1. **限时优惠**："现在下单立减 XX，活动只到今晚 12 点"——适合清仓/大促
2. **免费试用**："点击领取 7 天免费体验，不好用全额退"——适合订阅/课程
3. **立即下单**："点击下方小黄车，把 XX 带回家"——适合直播/短视频带货
4. **咨询客服**："私信，客服 1 对 1 给你搭配方案"——适合高客单/定制
5. **关注领取**："关注并私信，领 XX 专属优惠券"——适合涨粉阶段
6. **分享裂变**："转发给那个最需要的人，你们一起省"——适合社交裂变

### 四、产品卖点提炼 Prompt 模板

```
请从以下产品描述中提炼 3-5 个核心卖点：
{product_name}
{product_desc}
{audience}

要求：
1. 每个卖点 ≤20 字，说人话，不说参数
2. 按"能让用户心动的程度"排序，最强的放第一
3. 区分"功能卖点"和"情绪卖点"，至少各 1 个
4. 输出格式：
卖点1：xxx（功能/情绪）
卖点2：xxx（功能/情绪）
...
痛点：xxx（一句话，用户现在没它会怎样）
```

### 五、广告脚本生成 Prompt 模板

```
你是短视频广告编导。用下面的方法论写一条 {seconds} 秒产品广告口播脚本：

{product_name}
{selling_points}
{audience}
{hook_type}（从 5 种里选最匹配的）
{body_type}（从 5 种里选最匹配的）
{cta_type}（从 6 种里选最匹配的）

输出格式（严格遵守）：
HOOK: <前3秒文案，一句话>
BODY: <正文口播，口语化，一句一断句>
CTA: <结尾行动号召，一句话>
TERMS: <3-4 个英文素材检索词，逗号分隔，给 Pexels 搜视频用>

约束：总字数 {seconds} 秒≈{word_count} 字；禁用"首先/其次/总之"；不许编造没有的产品功效。
```

### 六、分镜脚本格式

每个镜头一行，字段用 `|` 分隔：

```
镜头1 | 0-3s | 画面：清晨闹钟特写转场 | 口播：Hook 文案 | 字幕：同口播
镜头2 | 3-8s | 画面：产品使用近景 | 口播：卖点1 | 字幕：同口播
...
```

- 每个镜头 3–5 秒；画面描述要具体到"什么景别+什么动作"（给 AI 生图/Pexels 检索用）
- 字幕默认 = 口播原文（可在视频配置里关掉字幕）

## 诚实约束

- 产品描述里没有的功效/数据，**不许编造**，缺失处写"（待补充）"
- 数字（价格/折扣/人数）必须来自输入，模型不得臆造
- 医疗/金融类产品：不许承诺疗效/收益，CTA 只用"咨询客服"类
