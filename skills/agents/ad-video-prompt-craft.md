# AI 广告视频提示词工程技能

> 方法论借鉴 creatify-ai/ai-ad-prompt-guide（MIT）与 dev.to 社区的 7-slot 产品镜头公式，重写为中文并适配一幕 AI 广告视频生成 Agent。只用方法论思想，不复制原文代码。

## 适用场景

- 广告创意视频 Agent（`ad_video` stage）：把分镜转成视频大模型能直接吃的提示词
- 产品广告：产品必须全片长得一模一样，不能"换脸"

## 一、SLCT 四要素框架

每个有效的 AI 视频生成提示词必须包含四个要素，缺一不可：

| 要素 | 英文 | 说明 | 示例 |
|------|------|------|------|
| S 主体 | Subject | 画面里有什么，精确到材质/颜色/细节 | 一瓶 500ml 磨砂玻璃面的保湿喷雾，白色泵头 |
| L 光影 | Lighting/Look | 光线方向、氛围、色调 | 清晨柔光从左侧窗户洒入，暖白色调 |
| C 机位运镜 | Camera | 景别 + 运镜方式（用电影术语） | 特写，缓慢推镜（push-in） |
| T 技术 | Technical | 画幅、时长、风格、帧率 | 9:16 竖屏，3 秒，写实摄影风格 |

**铁律**：四个要素缺一个，生成结果就失控一个维度。写完提示词后逐项打勾。

## 二、7 槽位产品镜头公式

```
[1 产品精确描述] + [2 一个动作] + [3 一个运镜] + [4 镜头与灯光] + [5 场景] + [6 写实风格词] + [7 时长]
```

示例（15 秒护手霜广告第 2 镜）：

> [1] 一支白色磨砂管身的护手霜，管身印有金色 "YIMU" 字样
> [2] 一只手挤出乳白色膏体，涂抹在另一只手背上
> [3] 缓慢推镜（slow push-in）
> [4] 微距特写，柔光箱打出的均匀漫反射
> [5] 米白色大理石台面背景，旁边有一株小型绿植
> [6] 高端美妆广告摄影风格，超写实，8K 质感
> [7] 3 秒

### 产品描述全片一致铁律

- **第 1 槽位的产品描述，全片所有镜头逐字复制粘贴，不许改写、不许增删**
- 先定稿一句"产品标准描述"（≤40 字），存入分镜上下文，后续镜头直接引用
- 人物也一样：出镜人物的外貌描述定稿后全片复用

## 三、幻觉预防 5 规则

1. **空间描述明确化**：不说"旁边"，说"画面左侧 1/3 处"；不说"后面"，说"背景虚化的书架前"
2. **每场景最多 3 个主体**：超过 3 个，模型必乱。产品 + 手 + 背景道具 = 3 个封顶
3. **不用否定句**：不说"没有文字"，说"画面干净，只有产品"；模型听不懂"不要"
4. **用现实参照物锚定**：不说"高级感打光"，说"Vogue 封面式伦勃朗光"；不说"好看的色调"，说"爱马仕橙主色调"
5. **数量词精确化**：不说"几滴水珠"，说"3 颗晶莹水珠挂在瓶身"；不说"很多人"，说"2 位 25 岁左右的女性"

## 四、运镜术语表（用电影术语，模型更懂）

| 中文 | 英文术语 | 适用场景 |
|------|----------|----------|
| 推镜 | push-in / dolly-in | 产品特写，情绪递进 |
| 拉镜 | pull-back / dolly-out | 揭示场景，建立空间感 |
| 横移 | tracking / lateral move | 展示产品线/货架 |
| 环绕 | orbit / arc shot | 产品 360° 展示，高级感 |
| 手持跟拍 | handheld follow | UGC 真实感，日常植入 |
| 固定机位 | static / locked-off | 口播、证言，可靠感 |
| 急推 | crash zoom / whip push | Hook 开场，强冲击 |

**口语 vs 术语**：不说"镜头慢慢靠近产品"，说"slow push-in on product"。

## 五、UGC 三公式（真人出镜类广告）

1. **开箱公式**：`[人物描述] + unboxing + [产品] + 自然光 + 轻微手持晃动 + 手机质感 + [惊喜表情/动作]`
2. **产品测评公式**：`[人物] + 拿起[产品] + 对着镜头说话感 + 生活化背景 + 自然光`
3. **日常植入公式**：`[人物] + 正在[日常动作] + [产品]自然出现在画面中 + 不看镜头`

反精致化关键词（UGC 必备）：手机质感、轻微手抖、自然光、生活化背景、不完美构图。

## 六、产品特写两技巧

1. **Hero 定妆照**：产品居中，纯色背景，伦勃朗光，缓慢 15° 环绕，3 秒
2. **Before/After 分屏**：左半屏"使用前"，右半屏"使用后"，中间有清晰分界线，固定机位

## 七、Pass³ 质检（生成后必过三遍）

1. **物理检查**：重力对吗（东西没飘）、反射合理吗、阴影方向一致吗、产品比例没变形吧
2. **细节检查**：手指数量对吗、产品上的文字可读吗（不可读就后期叠字，不要进提示词）、面部对称吗、边缘干净吗
3. **品牌检查**：色调符合品牌吗、产品一眼能认出来吗、有没有"一眼 AI"的塑料感

**质检失败直接重生成，不要试图修图**——重写提示词比修图快 10 倍。

## 八、与广告视频流水线的配合

- 本技能服务于 `ad_video` stage：输入是分镜表（镜头/时长/画面描述/口播），输出是每个镜头的 7 槽位英文提示词
- 产品标准描述来自 `analyze_reference_images()` 的视觉分析结果
- 提示词用英文写（视频模型对英文理解更好），产品名保留原文
