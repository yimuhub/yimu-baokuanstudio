# Skill：差异化选题

> 移植自项目 A `app/idea.py`（generate_ideas）。纯规则方法论，无需 LLM 即可跑通打分部分。

## 适用场景

- 有一批热榜/对标内容，想从中挖出"别人没写过"的切入角度
- 判断一个话题是蓝海还是红海，决定要不要追
- 给创作者出一份"选题作业单"（多个备选 + 机会排序）

## 输入

- `domain`：领域（如 AI、美食、职场）
- `topic`：话题关键词（可选）
- `days`：时间窗，默认 3 天
- 对标内容样本：标题 + 平台 + 链接（至少 20 条才有统计意义）

## 输出

选题作业单，含四部分：
1. `ideas[]`：按机会分 opportunity 从高到低排的选题（每个挂对标条目和链接，可回溯）
2. `cross_ideas`：跨话题交叉选题
3. `platform_gaps`：平台错位机会（某话题在 A 平台有量、在 B 平台为 0）
4. `structures`：可选，对标骨架

## 核心规则

### 差异化三源（找切入点的三个方向）

1. **簇内缺口**：同一个话题里，大家都写「A」，几乎没人碰「B」——B 就是切入口
2. **簇间交叉**：话题 X 和话题 Y 各自都热，用 Y 的框架写 X，位置通常还没人占
3. **平台错位**：某话题在知乎/掘金有量，在公众号/小红书是 0 条——搬运即选题

### 红海标签与机会分

- share（话题占全样本比例）≥ 0.30 → 红海；≥ 0.12 → 竞争适中；否则蓝海
- 机会分 = 0.5 × 热度（share/0.10 封顶）+ 0.5 × 缺口（缺口词数/8 封顶）；share > 0.45 再打 7 折

### 缺口词三重过滤

1. 词频 df ≥ 2（只出现一次的不算信号）
2. 横跨 ≥ 2 个平台（单平台自嗨不算缺口）
3. 不是更长词的截断子串（避免"人工"和"人工智能"重复计数）

### 标题模板（8 类，`{k1}`=缺口词、`{k2}`=话题词）

- 疑问钩子 / 数字清单 / 亲测经验 / 对比取舍 / 警示避雷 / 断言结论 / 时效突发 / 免费白嫖

## 质量门

- [ ] 每个选题都能回溯到具体对标条目和链接（不编造、只给方向不定死内容）
- [ ] 缺口词不从"共识词"兜底（否则会产出"为什么大家都在说 XX"这类自指空转的废话选题）
- [ ] 红海话题必须配差异化角度，裸追热点不予通过
