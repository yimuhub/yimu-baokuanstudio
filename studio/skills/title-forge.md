# Skill：标题锻造

> 移植自项目 A `app/title.py`（generate_titles）。16 法生成 + 8 维评分 + 诚实预测。

## 适用场景

- 成稿已定，批量生成候选标题并排序
- 需要"稳健版 / 冲击版 / 搜索版"三版精选 + A/B 测试建议

## 输入

- 成稿 draft（空稿拒绝）；`keyword`；`platform` 平台码

## 输出

- 候选标题数组（每条：title / method / score / risk / cover 封面短标题）
- `recommend` 五角色：综合首选 / 稳健 / 传播 / 搜索 / 实验
- `pick_three` 三版精选：稳健版 / 冲击版 / 搜索版
- `predict_ctr`：0–100 相对指数 + ±7 区间（**不是实测点击率**，必须带 disclaimer 到界面）
- `ab_advice`：A/B 建议（只认单变量）

## 核心规则

### 16 法（至少覆盖 6 种不同方法，不要 8 个一个套路）

强时效 / 实体锚定 / 数字反差 / 首次-唯一-极值 / 揭秘 / 冲突对立 / 反差转折 /
亲测态度转变 / 任务结果 / 生活痛点 / 身份与场景 / 收益与损失 /
对话剧本 / 问题悬念 / 隐藏机制与真相 / 具体场景画面

### 8 维评分（百分制逐维）

内容兑现度 / 读者相关性 / 具体性 / 好奇缺口 / 收益或后果 / 情绪与冲突 / 清晰与节奏 / 独特性

### 风险三级

- 低：事实都在正文里
- 中：强情绪或需核验
- 高：未证实的负面指控——**不得做首选**

### 红线（逐字保留）

- 不捏造数字 / 体验 / 首发；缺口再大，点进去必须兑现
- 只改表达，不加正文没有的东西

### 长度约束

- 封面短标题 ≤ 12 字
- 平台上限：公众号 32 / 小红书 20 / 头条 30 / 微博 24（字），超长扣分

## 质量门

- [ ] 高风险标题不得出现在首选位
- [ ] `predict_ctr` 必须原样带"相对指数、非实测" disclaimer 端到界面
- [ ] A/B 建议不是单变量对照的，如实称"对照"，不叫 A/B
- [ ] 无可用模型走规则兜底时，必须如实写明原因
