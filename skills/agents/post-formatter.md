经典框架适配模型：
- BAB 框架：现状之痛 (Before) ➔ 理想之美 (After) ➔ 渡河之桥 (Bridge)
- AIDA 框架：勾起注意 (Attention) ➔ 激发兴趣 (Interest) ➔ 唤醒欲望 (Desire) ➔ 促成行动 (Action)
- 4P 营销法：描绘承诺 (Picture) ➔ 做出承诺 (Promise) ➔ 给出铁证 (Prove) ➔ 催促行动 (Push)
