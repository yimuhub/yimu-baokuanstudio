04 / INSTALL

安装与部署

安装方式以官方 GitHub 仓库为准 · 所有版本与更新来源：github.com/yimuhub/yimu-baokuanstudio
macOS / Linux
# 1 · 克隆官方仓库
git clone https://github.com/yimuhub/yimu-baokuanstudio.git
cd yimu-baokuanstudio

# 2 · 创建并激活虚拟环境 (Python 3.12+)
python3.12 -m venv .venv && source .venv/bin/activate

# 3 · 安装依赖
pip install -r requirements.txt

# 4 · 配置环境变量
cp .env.example .env   # 填写 YIMU_SECRET_KEY 与 ADMIN_PASSWORD

# 5 · 启动服务
python -m uvicorn web.admin:app --host 127.0.0.1 --port 8790
Windows
# 方式一 · 一键启动（双击即用）
# 项目根目录 启动一幕V8.bat / 升级一幕V8.bat，双击即可

# 方式二 · 命令行
git clone https://github.com/yimuhub/yimu-baokuanstudio.git
cd yimu-baokuanstudio
python -m venv .venv && call .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn web.admin:app --host 127.0.0.1 --port 8790
Docker
git clone https://github.com/yimuhub/yimu-baokuanstudio.git
cd yimu-baokuanstudio && docker compose up -d

获取最新版本

一切版本与更新均以 GitHub Releases 为准：历史版本永久归档冻结（v8.3.33 / v8.3.2），新版本直接发布并附升级对照。在线热更新检测内置于系统 core/updater.py（Git + GitHub API 双通道）。

git checkout v8.3.33 冻结归档版 · git checkout v9.0.0 主里程碑 · 或直接 git pull 获取 latest main。
