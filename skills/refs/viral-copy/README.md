# Viral Copywriting Skill

一套可直接使用的 AI skill 工具包——把关健明《爆款文案》中的销售型文案方法，蒸馏成 14 个可单独触发、也可组合调用的写作与诊断模块。

这不是一本书的摘要页。书是这些 skill 的来源，不是首页主角。

## 这套 skills 能解决什么问题

- 想从零写一篇能卖货的推文、详情页、广告或社群文案
- 已有文案转化率低，但不知道标题、欲望、信任、下单哪一步出了问题
- 产品卖点很多，却写不出让读者立刻想买的表达
- 缺少权威、证据、顾客评价或价格理由，读者看完还是不信、不买
- 需要把一套销售文案拆成可复用、可诊断、可组合的 agent workflow

## 蒸馏了什么

从《爆款文案》中提取了 14 个经过三重验证的 skill，围绕“标题抓眼球 -> 激发购买欲 -> 赢得信任 -> 引导马上下单”四步销售漏斗组织。

### 元框架

- `copywriting-four-step-system`：文案卖货四步骤系统，负责整体结构规划、诊断和组合其他 skill

### 激发购买欲望

- `sensory-occupation`：用六感描写让读者在脑海中“试用”产品
- `fear-appeal`：用痛苦场景 + 严重后果激发紧迫感
- `cognitive-contrast`：先写竞品弱点，再写我方优势，用对比放大差异
- `usage-scenario`：设计具体使用场景，替读者完成联想
- `customer-testimonial`：精选击中核心需求的真实评价和畅销暗示

### 赢得读者信任

- `authority-transfer`：用权威高地位 + 高标准两步转移信任
- `factual-evidence`：把专业数据翻译成读者能感知的事实或实验

### 引导马上下单

- `price-anchor`：设置高价参照物，让实际价格显得更划算
- `cost-accounting`：按每天成本或长期节省帮读者算账
- `justified-consumption`：把购买重构为上进、送礼、健康或孩子相关的正当理由

### 标题写作

- `news-editorial-title`：新闻主角 + 即时性词 + 重大新闻词
- `friend-chat-title`：“你” + 口语词 + 惊叹词
- `practical-tip-title`：具体苦恼 + 完美结局或破解方法

## 效果示例

### 示例 1：诊断一篇不卖货的文案

**用户问题**

> “这是我的新品详情页，流量还可以，但下单很少，帮我看看问题在哪。”

**skill 如何判断**

- 先触发 `copywriting-four-step-system`，按四步检查标题、购买欲、信任、下单
- 如果只是罗列卖点，调用 `sensory-occupation` 或 `cognitive-contrast` 强化购买欲
- 如果读者不信，调用 `authority-transfer`、`factual-evidence` 或 `customer-testimonial`
- 如果读者觉得贵，调用 `price-anchor`、`cost-accounting` 或 `justified-consumption`

**最终回答示例**

> 这篇详情页的问题不在信息少，而在“购买欲”和“信任”没有交替叠加。前半段一直讲参数，读者没有在脑海里看到自己使用产品的画面；后半段突然给优惠，也没有解释为什么值得现在买。建议改成 1-232-34 结构：标题先抓住具体痛点，第一段用使用场景制造画面，第二段用事实证明消除疑虑，再用价格锚点和算账收尾。

### 示例 2：写一篇完整销售推文

**用户问题**

> “帮我给一款便携冲牙器写一篇公众号卖货文案。”

**skill 如何判断**

- 用 `friend-chat-title` 写出低防备标题
- 用 `fear-appeal` 写牙缝残留和口气尴尬的具体场景
- 用 `sensory-occupation` 描写冲洗后的清爽感
- 用 `factual-evidence` 把水压、续航、防水等级翻译成读者懂的事实
- 用 `price-anchor` 和 `cost-accounting` 引导下单

## 这些 skill 是怎么生成出来的

这套 skill 使用 **cangjie-skill** 的 RIA-TV++ 流水线生成，整个流程分六个阶段：

1. **整书理解（Adler 分析）**——用 Mortimer Adler 的分析阅读法，对全书做结构、解释、批判、应用四步拆解，产出 `BOOK_OVERVIEW.md`
2. **并行提取**——同时派 5 个专项提取器（框架、原则、案例、反例、术语），从原文中提取候选方法论单元
3. **三重验证筛选**——每个候选必须通过三项检验：书中至少有 2 处独立佐证（跨域）、能回答书中未明说的新问题（预测力）、不是常识（独特性）
4. **RIA++ 构造**——将验证通过的内容按 R（原文引用）/ I（用自己的话重写）/ A1（书中案例）/ A2（未来触发场景）/ E（可执行步骤）/ B（边界与盲点）六个维度结构化
5. **Zettelkasten 链接**——找出 skill 之间的依赖、对比、组合关系，生成 `INDEX.md` 和引用图
6. **压力测试**——为每个 skill 设计包含诱饵题的测试用例，未通过的回炉重做

## 如何使用

1. 先浏览 `INDEX.md` 了解 14 个 skill 的全景图和推荐学习顺序
2. 找到与你当前问题相关的 `*/SKILL.md`，直接使用触发条件和执行步骤
3. 当问题是“整篇文案怎么写”或“为什么不卖货”时，优先使用 `copywriting-four-step-system`
4. 将 skill 接入你的 agent 框架，或把 prompt 作为独立工具使用
