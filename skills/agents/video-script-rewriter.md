# Skill：短视频多模式文案改写 (AI Video Script Rewriter)

> 深度适配短视频工业化生产全流程，将长文、草稿或灵感迅速提炼重构成极具视听穿透力的不同风格口播文案。

## 适用场景
- 影音工坊 AI 短视频生成前的文案一键模式化升级
- 针对不同出镜与呈现载体（数字人驱动 / 权威快讯 / B-roll 混剪堆积 / 剧情微短剧 / 电商带货）快速变换文本结构与镜头指令
- 自动计算字数与预估朗读时长，无缝匹配视频总时长（如 15s / 30s / 60s）

## 支持的 6 大爆款模式

1. **权威新闻快报 (news)**：
   - 特点：播音员腔调、倒金字塔结构、核心事实第一时间爆出，极强公信力。
   - 标注：含 [画面: 现场全景/数据图表] 等镜头指引。

2. **AI 数字人口播 (avatar)**：
   - 特点：第一人称一对一对话视角、口语化感染力、黄金3秒强钩子。
   - 标注：自然穿插数字人肢体微表情标记，如 `[微笑视镜]` `[手势强调]` `[停顿0.5s]`。

3. **视频堆积/切片模式 (stacking)**：
   - 特点：视觉快切、高密度信息轰炸、短促有力的卡点短句。
   - 标注：深度嵌入 `[快切镜头: XX][音效: 嗖]` `[B-roll画面: XX]`，专为剪辑卡点设计。

4. **悬念反转故事 (story)**：
   - 特点：强悬念开局、戏剧性冲突、打破常理的反转爆发、金句情感升华。

5. **爆款带货种草 (selling)**：
   - 特点：PAS模型、痛点暴击、场景代入、前后对比反差、强促单 CTA 闭环。

6. **认知金句共鸣 (quote)**：
   - 特点：扎心现实切入、深层人性洞察、高密度哲思金句、高点赞高收藏。

## 规范与质量控制
- 严禁任何 AI 空洞废话（如"综上所述"、"随着科技发展"、"今天我们聊聊"）。
- 严格受控于目标时长与字数（按约 4.2 字/秒计算）。
- 所有动作/镜头标记均采用方括号 `[...]` 标注，便于前端识别与视频生成管线解析。
